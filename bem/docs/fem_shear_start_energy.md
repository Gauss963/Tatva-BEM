# FEM 剪切起點的已保存能量

2026-11-04：只讀檢查同 end `0.015625 mm`、h2、float64 graded FEM 的配置、
原始碼快照與 HDF5，沒有重跑或更動原 Tatva。
[資料與來源](fem_shear_start_energy_results.json)保存六筆診斷列及比較範圍。

該案例先求 healed 靜態預載，再維持法向載入 2 ms；初始速度 `v0=0`，
顯式半步速度包含 `0.5*dt*a0`。
`normal_relaxation_time=null`，所以沒有採用原程式的 normal-relaxation 速度重設分支。
剪切開始時只按原設定重設累積弱化記憶，保留塑性偏移。

法向階段末筆診斷的動能為 `3.04235e-16`，彈性與界面儲存能量之和約 `5213.06`，
比值 `5.8360e-20`。初始與法向末端的 bulk displacement 存檔最大差為
moving `9.5367e-7 mm`、stationary `5.9605e-8 mm`；這些 bulk 檔案為 float32。
已保存的塑性滑移、累積滑移、摩擦係數逐位相同，強度最大差 `1.9074e-6`。

這些資料未顯示足以解釋主要場誤差的初始全域動能。
檔案沒有保存 bulk velocity，因此不能由這項核對宣稱逐點初速完全一致，
亦不能將它當作靜態場、破裂分支或時間／空間收斂的證明。
完整 BEM／FEM 一致性與同精度速度／穩定性優勢仍待完成。
