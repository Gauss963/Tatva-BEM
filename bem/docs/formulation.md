# Formulation and discrete conventions

## Continuum problem

Each finite, homogeneous domain satisfies

```text
rho * u_tt = mu * Delta(u) + (lambda+mu) * grad(div(u))
sigma = lambda * div(u) * I + mu * (grad(u) + grad(u).T)
t = sigma * outward_normal
```

This is plane strain, with lambda = E nu / ((1+nu)(1-2nu)). Density appears in
the wave kernels, not in an arbitrary boundary mass matrix.

For Re(s)>0 define ks=s/cs, kp=s/cp, phi_k(r)=K0(k r)/(2 pi). The displacement
fundamental tensor is

```text
G(s) = [phi_s I - Hessian(phi_s - phi_p) / ks^2] / mu
```

It solves `(rho s^2 - mu Delta - (lambda+mu) grad div) G = delta I`.
`kernels.py` differentiates this radial tensor analytically. Small Bessel
arguments use the K0 power/log series before differentiation to avoid loss
of significance from cancelling leading K1 terms.

Separation is **source minus target**. The double-layer tensor is
`D_ij=(T_source G_i)_j`; source normals are outward. An inward-normal sign
change or an unnoticed transpose breaks the manufactured-wave tests.

## Boundary representation

For an interior domain, midpoint P0 collocation gives

```text
H(s) u = V(s) t
H(s) = 1/2 I + K(s)
W(s) = V(s)^(-1) H(s)
```

`u` and `t` are physical traces. The kernel is not the static DDM matrix
from Bem2d.jl. Self single-layer integrals use analytic Kelvin-log
subtraction; the smooth dynamic remainder uses the same Gauss nodes.
The self double-layer principal value at a straight panel midpoint is zero.
The 1/2 jump is added explicitly. No row-sum substitution is used for the
dynamic jump.

Off-diagonal panels use even-order Gauss-Legendre quadrature, default 20.
No mesh endpoints are collocation points. Corner singularities remain
mesh dependent; P0 collocation is not claimed to satisfy an exact discrete
energy identity.

## BDF2 convolution quadrature

```text
delta(zeta) = 3/2 - 2 zeta + zeta^2/2
W(delta(zeta)/dt) = sum_j weights[j] * zeta^j
t[n] = weights[0] u[n] + sum_{j=1}^n weights[j] u[n-j]
```

The weights are generated by conjugate-symmetric frequency samples on
`zeta=R exp(-2 pi i k/L)`, followed by IFFT and multiplication by `R^(-j)`.
FFT length is at least twice the requested number of time samples; the
default contour alias tolerance is 1e-10. Negative-time perturbations are
zero. The coefficients are generated for the complete requested horizon.

The implementation retains all weights and all past boundary displacements.
It performs the convolution directly: memory O(Nt Nb²), history work
O(Nt² Nb²), plus frequency-domain dense factorizations. This is intended as
a transparent reference, not a production fast-CQ implementation.

BDF2 is dissipative at high frequencies. Implicit integration removes an
explicit FEM CFL condition, but does not remove wave-resolution requirements
or guarantee a nonlinear contact step has a unique solution.

## Contact, constraints and platen

Separate domain operators couple only through the contact equations.
Boundary meshes are counterclockwise, with outward normals. Along x=200:

```text
normal closure = u_mx - u_sx
relative slip  = u_my - u_sy
p = kn max(normal closure, 0)
moving traction = (-p,-tau)
stationary traction = (+p,+tau)
```

Current displacement/pressure are implicit. Default friction strength uses
the previous accepted cumulative slip, as in the archived Tatva microstep.
Plastic correction and absolute cumulative increment are committed once
after the global Newton solve. The coefficient actually applied during the
step is saved separately from the updated cumulative slip.

The optional updated-state softening law has a denominator `kt-p*dmu/dc`.
It rejects nonunique local returns explicitly. It is not silently used as
a substitute for the original previous-state update.

A prolongation P eliminates prescribed supports and gives every platen
uy DOF the same scalar d. Residual forces are projected with
`P.T diag(panel_length)`, including the spring resultant
`k*platen_width*(d-D)`. Contact panels pair at equal y and equal length,
so their contact forces cancel pairwise with the same quadrature measure.

## Static lift and event-16 initialization

Nonzero initial FEM displacement cannot simply be inserted into a
zero-initial-condition convolution. Instead, solve a BEM static equilibrium
`(u0,t0)` using the measured plastic slip, original normal pressure and
restart actuator value. For an admissible static equilibrium, write

```text
u = u0 + v
t = t0 + CQ_W(v)
v(0) = 0, v_t(0) = 0
```

Because u0 solves the static interior equation, v satisfies the homogeneous
initial elastodynamic equation. This is valid for the BEM equilibrium being
constructed, but it is not an exact import of the FEM interior initial field
or of prior dynamic waves. Inadmissible friction states are rejected unless
the caller explicitly selects a state-changing static relaxation.

The short event run starts at the shear-phase origin and holds the normal
pressure at 16 MPa. D initially increases at 20 mm/s. Once every contact
station reaches Dc, the original actuator-hold criterion is applied.

## Primary references

- [Boundary integral equation methods for the solution of scattering and transmission 2D elastodynamic problems](https://academic.oup.com/imamat/article/87/4/647/6674490): two-dimensional elastic layer potentials and boundary operators.
- [Fast and data sparse time domain BEM for elastodynamics](https://www.sciencedirect.com/science/article/abs/pii/S0955799714001891): elastodynamic CQ and the cost of temporal convolution.
- [Convolution quadrature time-domain boundary element method for 2-D and 3-D elastodynamic analyses in general anisotropic elastic solids](https://www.sciencedirect.com/science/article/pii/S0955799713002348): Laplace-domain kernels used for transient elastodynamics.

The finite-bar analytic solution in `benchmarks.py` is derived independently
by expanding `sinh(k(L-x))/(Z s cosh(kL))` into delayed incident/reflected
waves. It is not fitted to either Tatva or the computed BEM curve.
